RELEASE NOTES

AutoTasker Version 3.9.0 Changelog

  • Pure Event-Driven Engine: Completely removed persistent background service process and notification bar icon. Zero idle battery and RAM consumption.
  • Dynamic Package Version Resolution: Replaced hardcoded update checks with dynamic `PackageInfo` version code inspection to eliminate repeat update prompts.
  • 100% Package Visibility: Integrated `QUERY_ALL_PACKAGES` permission and launcher intent queries. Discovers all 3rd-party user apps (WhatsApp, Instagram, etc.).
  • Direct Card Click to Edit: Workflow task cards open the editor directly on tap, with streamlined card action button spacing.
  • Smart Country Code Handling: Pre-fills default India `+91` code for phone triggers and automated phone call actions.

System Requirements & Privacy

Requires Android 8.0 (Oreo) or higher (API level 26+). 100% Privacy Focused — all automation rules, photos, and logs run locally on your device without third-party tracking.
