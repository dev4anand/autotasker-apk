AutoTasker Version 4.1.0 Changelog

  • Interactive Action Parameters & 1-Tap Pills: Replaced confusing input boxes with explicit 1-tap choice pills (ON, OFF, SILENT, VIBRATE, NORMAL, FRONT, BACK, 0-100%) and clear instructions for every action!
  • Bluetooth Control Action (`TOGGLE_BLUETOOTH`): Added new action to turn Bluetooth ON, OFF, or open the system Bluetooth settings panel.
