RELEASE NOTES

AutoTasker Version 3.7.0 Changelog

  • Bulletproof Update Engine: Automatic cache-busting, redirect handling, and automatic Android 8.0+ Unknown App Installation permission prompt.
  • Offline Task Queue: Internet-dependent actions triggered in Airplane mode or offline are automatically queued into Room DB and sent as soon as network connects.
  • Open Particular App Action: Added `OPEN_APP` action with interactive Package Manager app picker to select and open any installed application.
  • AM/PM & Recurrence Scheduling: Alarm scheduling supports 12-hour AM/PM input, target date (`YYYY-MM-DD`), and Daily, Monthly, or Yearly recurrence rules.
  • Event Trigger Reliability: Fixed `SCREEN_ON` dynamic broadcast listening, `LOCATION_STATE_CHANGED` GPS provider detection, `AIRPLANE_MODE` target state filtering, and background service recovery.

System Requirements & Privacy

Requires Android 8.0 (Oreo) or higher (API level 26+). 100% Privacy Focused — all automation rules, photos, and logs run locally on your device without third-party tracking.
